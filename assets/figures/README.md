# Figure Assets

These figures were selected from the complete IJCV manuscript source to provide
visual context in the GitHub README.

They cover:

- the end-to-end HDR processing pipeline;
- representative samples from the survey dataset;
- PQ and HLG transfer characteristics;
- a global/local/deep-learning TMO comparison;
- TMQI-II category distributions; and
- subjective JOD rankings.

Traditional TMO examples and the associated benchmark statistics come from the
MATLAB experiment pipeline. Deep-learning examples come from the corresponding
original model implementations. They are not generated by the reference Python
port in `hdrtmo/`.
